## Latest from GitHub

- Automate a weekday summary of new, closed, and stale issues with the [Daily Issues Report workflow](https://awesome-copilot.github.com/workflows/) from Awesome Copilot.
- Find inactive repositories in your organization and get an archival recommendation with the [OSPO Stale Repository Report workflow](https://awesome-copilot.github.com/workflows/) from Awesome Copilot.
- Ask `/relevance-check` on an issue or pull request to get an assessment of whether it is still relevant, using the [Relevance Check workflow](https://awesome-copilot.github.com/workflows/) from Awesome Copilot.
